# CareerPath – AI Career Counsellor

CareerPath is an AI-powered career counselling web application developed as my final-year project. It helps users assess their profiles, explore suitable career paths, receive personalized recommendations, follow learning roadmaps, track their progress, and access useful learning resources.

## ✨ Features

- 👤 User registration and login
- 📋 Profile assessment
- 🎯 Personalized career recommendations
- 🗺️ Career and learning roadmaps
- 📚 Learning resources
- 📊 Performance and progress tracking
- 🏆 Achievements and tasks
- 📝 Career-related assessments and tests
- 🔔 Notifications
- 📈 Interactive dashboard
